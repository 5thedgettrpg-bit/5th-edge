## Usage notes

The supplied license certificate states that Premium Plan use includes digital copies on websites and online media. Keep these resources as visual elements inside the 5th Edge site and do not expose this folder as a downloadable asset library.

When an image is placed on a page, use descriptive alt text for accessibility. Attribution text can be added in the site legal/credits page so it does not clutter the visual design.
