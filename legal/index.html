Legal & Licensing

This page identifies the open rules sources and licenses used by 5th Edge, and separates those sources from original 5th Edge material.

Independent project

5th Edge is an independent third-party tabletop rules project. It is not an official Wizards of the Coast product. Third-party product names and trademarks remain the property of their respective owners.

The public-facing compatibility wording used by 5th Edge is “5E compatible” or “compatible with fifth edition.”

System Reference Document 5.1

5th Edge primarily targets fifth-edition rules compatibility and may incorporate, adapt, or reference material from System Reference Document 5.1.

  • Publisher: Wizards of the Coast LLC
  • License: Creative Commons Attribution 4.0 International
  • Official SRD source
  • CC BY 4.0 legal code

The official SRD 5.1 document contains the publisher-supplied attribution language that applies when SRD 5.1 material is used.

System Reference Document 5.2.1

Where 5th Edge intentionally adopts material from the newer revised fifth-edition SRD, that material is sourced from System Reference Document 5.2.1.

  • Publisher: Wizards of the Coast LLC
  • License: Creative Commons Attribution 4.0 International
  • Official SRD 5.2.1 source
  • CC BY 4.0 legal code

The official SRD 5.2.1 document contains the publisher-supplied attribution language that applies when SRD 5.2.1 material is used.

Original 5th Edge material

Rules revisions, class redesigns, original wording, site code, visual design, branding, and other material created specifically for 5th Edge are separate from the underlying SRD material unless a page states otherwise.

Other books and references

Material that is not part of an SRD should not be reproduced as though it were open content. References to non-SRD books should be limited to appropriate citations, compatibility references, or separately authorized material.
